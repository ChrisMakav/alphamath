Follow-up to [[licence-l3-gap-fill]] (which added probabilites-l3/geometrie-l3/informatique-l3 and integrated the Fourier lesson). This batch adds 3 more L3 courses to `lib/licence-courses.ts`, chosen to avoid duplicating anything in L1/L2/L3 (verified by listing every existing course's id/subject/schoolLevel/title before choosing topics):

1. `mesure-l3` (slug `mesure-l3-theorie-integration-lebesgue`, subject analyse) — lessons `mes3-l3-1` (tribus et mesures), `mes3-l3-2` (fonctions mesurables et construction de l'intégrale de Lebesgue), `mes3-l3-3` (théorèmes de convergence : monotone, Fatou, dominée). Natural follow-up to `topologie-l2` (metric spaces) and the Fourier lesson `anal3-l3-4`.
2. `hilbert-l3` (slug `hilbert-l3-analyse-fonctionnelle-espaces-hilbert`, subject analyse) — lessons `hilb3-l3-1` (produit scalaire, Cauchy-Schwarz, espaces préhilbertiens), `hilb3-l3-2` (projection orthogonale, Gram-Schmidt), `hilb3-l3-3` (bases hilbertiennes, Bessel, Parseval — explicitly closes the loop back to the Fourier lesson, reusing the dents-de-scie example to re-derive ζ(2)=π²/6 via the general Hilbert-space Parseval identity).
3. `groupes-l3` (slug `groupes-l3-actions-sylow`, subject algebre) — lessons `grp3-l3-1` (actions de groupe, orbite-stabilisateur, équation aux classes), `grp3-l3-2` (p-groupes, centre non trivial, Sylow I), `grp3-l3-3` (Sylow II/III, classification d'ordres 12/15/21/35/99, contre-exemples S3/A4/A5). Fills the gap that `algebre-l3` only covered reduction of endomorphisms.

**Verification routine actually followed this time** (all programmatic, on the compiled catalog not just source files):
- `npx tsc --noEmit` → clean on first attempt after fixes (exit 0).
- Duplicate check via the same Node script pattern as before (monkey-patching `Module._resolveFilename` for `./licence-courses` + a custom `.ts` require extension via `ts.transpileModule`, then walking `COURSES` from `seed-data.ts`): 102 total courses (was 99), zero new duplicates — only the same 16 pre-existing false positives (id===slug courses + cross-course lesson slug collisions) already documented, confirmed unchanged via `git stash` diff before/after.
- 5/5/5 split verified on the **compiled** `COURSES` array (not the raw `.ts` source) for all 9 new lessons: all OK.

**Bug recurrence (3rd and 4th time in two sessions): real newlines inside double-quoted `explanation`/`modelAnswer` strings.** Despite an explicit instruction in this session's brief to watch for this exact bug, it recurred in ALL FOUR new course files (14 occurrences in `l3-mesure.ts`, 15 in `l3-hilbert.ts`, 14 in `l3-groupes.ts`, not even counting a similar count likely in any future file) — writing long multi-paragraph mathematical explanations with real line breaks for readability is apparently a very strong reflex that survives explicit warnings. **Mitigation that worked:** reused the exact same `fix_multiline_strings.py` script from the previous session (line-scanning state machine that detects an opened-but-unclosed `key: "..."` field and joins continuation lines with literal `\n` until an unescaped closing quote is found) — ran it on each of the 4 files immediately after writing them, before even checking the 5/5/5 split. This is now the standard post-write step, not an occasional fix.

**New related bug found and fixed (not seen before):** in `l3-hilbert.ts`, two places referenced the Fourier lesson by writing its id inside backticks as inline-code-style markdown (`` `anal3-l3-4` ``) — this is invalid because the surrounding text is itself inside a double-quoted `explanation: "..."` string or a backtick-delimited `content:` template literal; in the template-literal case this would have closed the literal early (the classic backtick pitfall), and even inside a double-quoted string it's just stylistically wrong since backticks aren't meaningful there. Fixed by replacing with French guillemets-quoted lesson title (« Séries de Fourier ») instead of the raw id. **Lesson: never write a course/lesson id wrapped in backticks anywhere in lesson content or explanations — use the human-readable title in guillemets instead, every time, regardless of which string-delimiter context it's in.**

**5/5/5 manual drift pattern, now fully characterized across 2 sessions:** in 6 of the 9 new lessons here (mes3-l3-1, mes3-l3-3, hilb3-l3-2, hilb3-l3-3, grp3-l3-2, grp3-l3-3), the drift was specifically "exercise #10 (first 'open'-type proof exercise immediately after the MCQ/true_false block) marked `expert` when it should be `intermediaire`, pushing the count to 4 intermediaire / 6 expert instead of 5/5". One lesson (grp3-l3-3) additionally drifted at exercise #5 (marked `intermediaire` instead of `debutant`). **Root cause hypothesis: when writing 15 exercises in one pass, there's a reflex to treat the *type* transition (mcq/true_false → open) as implying a *difficulty* transition (intermediaire → expert) at the same boundary, even though the two axes are independent.** Mitigation: after writing, always run the Counter-based split check immediately, and when a 4/6 (or similar) imbalance appears at exactly the type-transition boundary, suspect exercise #10 (or wherever type changes) first.

**Topic selection process:** before writing anything, ran a Node script loading the live `lib/licence-courses.ts` to list every course's `id`/`subject`/`schoolLevel`/`title`, confirming the exact gap (L1=8, L2=9, L3=6 going in) and that none of the 4 candidate topics proposed (mesure/Lebesgue, Hilbert, groupes/Sylow, stats L3) overlapped existing content — explicitly dropped the "Statistiques L3" candidate as redundant with existing `stats-l2` + `probabilites-l3`.

**Final state after this batch:** L1=8, L2=9, **L3=9** courses (27 lessons total in L3, 405 exercises in L3 alone). Full catalog (`COURSES` in `lib/seed-data.ts`) = 102 courses. `npx tsc --noEmit` clean.
